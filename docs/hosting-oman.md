# الاستضافة والنسخ والبيئة التجريبية

التوصية لمصنع بثلاثة مستخدمين في صحار/عُمان، باتصال إنترنت مستقر، وبيانات يجب أن تبقى سريعة من المكتب والمصنع والإدارة.

## القرار

| البند | التوصية |
| --- | --- |
| شكل النظام | تطبيق ويب من المتصفح. اختصار سطح المكتب يفتح نفس الرابط (ملف `.url` أو «تثبيت التطبيق» من Chrome). لا حاجة لبرنامج ويندوز منفصل. |
| الدومين | اسم مثل `erp.gulffeed.om` أو نطاق `.com` إذا تأخر تسجيل `.om`. التسجيل عبر مسجّل عُماني معتمد أو Cloudflare. |
| التطبيق | Vercel للواجهة، أو خادم صغير واحد في **AWS البحرين `me-south-1`** إذا أردتم كل شيء داخل منطقة الشرق الأوسط على جهاز واحد. البحرين أقرب منطقة سحابية كبيرة إلى عُمان. |
| قاعدة البيانات | **Neon** أو **Supabase** أو RDS Postgres. عند استخدام Vercel اربطوا Postgres من لوحة Vercel Storage. فعّلوا الاستعادة لنقطة زمنية (PITR) لمدة **30 يوماً على الأقل**. |
| البيئة التجريبية | مشروع Preview على Vercel بمتغير `NEXT_PUBLIC_APP_ENV=staging` وقاعدة بيانات منفصلة. لا تُختبر التحديثات على قاعدة الإنتاج. |
| النسخ المحلي | كل حفظ يكتب ملفاً يومياً في `data/backups/erp-YYYY-MM-DD.json` ويحذف ما مضى عليه أكثر من 30 يوماً. على Vercel القرص غير دائم، لذلك النسخ المعتمد هو Postgres + تنزيل JSON من شاشة الإعدادات. |
| التزامن | النظام مصمم لثلاثة مستخدمين في الوقت نفسه. على خادم Node واحد يكفي قفل الكتابة الداخلي. على Vercel يُعتمد قفل الإصدار في جدول `ErpDocument`. |
| البريد | اضبطوا `SMTP_HOST` و`SMTP_PORT` و`SMTP_USER` و`SMTP_PASS` و`SMTP_FROM`. بدونها تبقى التنبيهات داخل النظام وتُعلَّم «لم يُضبط البريد». |

## متغيرات البيئة

| المتغير | الغرض |
| --- | --- |
| `DATABASE_URL` | رابط Postgres. بدونه يعمل النظام بملف محلي للتجربة. |
| `JWT_SECRET` | سر الجلسة. سلسلة طويلة عشوائية. |
| `SETUP_TOKEN` | تهيئة مستخدم Prisma الأولى إن لزم. |
| `NEXT_PUBLIC_APP_ENV` | `staging` لإظهار شارة البيئة التجريبية. |
| `ERP_DATA_DIR` | مجلد النسخة المحلية إن أردتم مساراً خارج المشروع. |
| `SMTP_*` | إرسال تنبيه نقص المخزون وطلبات الاعتماد. |

## النسخ لمدة 30 يوماً

1. في Neon أو RDS: فعّلوا الاحتفاظ 30 يوماً.
2. مهمة يومية (cron) على الخادم:
   ```bash
   pg_dump "$DATABASE_URL" -Fc -f "/var/backups/erp-$(date +%F).dump"
   find /var/backups -name 'erp-*.dump' -mtime +30 -delete
   ```
3. من داخل النظام: الإعدادات ← تنزيل نسخة احتياطية، واحفظوا الملف خارج المصنع مرة كل أسبوع على الأقل.

## سطح المكتب

في Chrome أو Edge: القائمة ← تثبيت التطبيق / إنشاء اختصار. أو أنشئوا ملفاً `اعلاف.url` يحتوي:

```
[InternetShortcut]
URL=https://erp.example.om
```

## ما يُؤجَّل دون إعادة بناء

- جهاز البصمة: يستورد إلى سجل الحضور نفسه (CSV أو API لاحق).
- الميزان: يملأ حقل الكمية في الاستلام أو الإنتاج عبر محوّل صغير، لأن الكمية أصلاً حقل مستقل في الحركة.
