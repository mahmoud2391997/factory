# خطة عمل نظام إدارة المصنع (ERP)
## مصنع أعلاف — سلطنة عُمان

**لمن هذا الملف؟** لصاحب العمل / الإدارة — بلغة أعمال واضحة بدون تفاصيل تقنية.  
**المدة:** أسبوعان كحد أقصى حتى يكون النظام جاهزاً للتجربة الفعلية ثم التشغيل.  
**تاريخ التقرير:** سبتمبر ٢٠٢٦  

---

## باختصار

نبني نظاماً عربياً لإدارة المصنع يغطي المسار اليومي:

**شراء مواد → تخزين → تصنيع → منتج نهائي → بيع / سحب → حسابات وتقارير**

الهدف أن تستطيع الإدارة في أي وقت الإجابة عن:
- من أين جاءت المواد؟ وأين رصيدها الآن؟
- ماذا دخل الإنتاج وماذا نتج فعلياً؟ وهل يوجد هدر أو انحراف؟
- كم بعنا؟ وما أثر ذلك على المخزون والمال؟
- من نفّذ كل عملية ومتى؟

## أين نحن الآن؟

| ما تم | الحالة |
|--------|--------|
| شاشة دخول آمنة وصلاحيات حسب الدور (مدير / مستودع / إنتاج…) | تم |
| واجهة عربية جاهزة بأقسام المصنع الرئيسية | تم |
| نسخة تجريبية للعرض حتى لو لم تُربط السيرفر بعد | تم |
| ربط السحابة وبدء النشر الأولي | تم |
| تسجيل المواد والمنتجات والمستودعات الثلاثة | تم |
| أرصدة مخزون دقيقة + دفتر حركات (لا تغيير بدون أثر) | تم ✓ — انظر `docs/day4-complete.md` |
| مسار شراء كامل (أمر → اعتماد → استلام) كتجربة يومية موحّدة | قادم (اليوم ٥) |
| محاسبة تلقائية وتقارير تشغيلية من البيانات الفعلية | جزئي / يتوسّع |
| إطلاق نهائي مع نسخة احتياطية وتسليم للإدارة | قادم |

**الخلاصة:** الأساس + نواة المخزون (اليوم ٤) جاهزان. الأيام التالية تركّز على مسار الشراء اليومي ثم التصنيع والمبيعات والتسليم.

|------|------------------|----------------------|
| **١** | دخول النظام + صلاحيات المستخدمين + المستودعات | تم ✓ |
| **٢** | أقسام النظام والشاشات الرئيسية بالعربية + نماذج كل الأقسام | تم ✓ — انظر `docs/day2-complete.md` |
| **٣** | تسجيل المواد الخام والمنتجات والمستودعات الثلاثة | تم ✓ — يمكن إضافة مادة/منتج ورؤيتها في القائمة |
| **٤** | أرصدة مخزون دقيقة مع سجل لكل حركة (لا تغيير بدون أثر) | تم ✓ — انظر `docs/day4-complete.md` |
| **٥** | المشتريات: أمر شراء ثم استلام بضاعة للمستودع | مسار: مورد → طلب → استلام → الرصيد يزيد |
| **٦** | تحويل بين المستودعات + تعديل مخزون بسبب واضح وموافقة | التحويل يغيّر الرصيدين ويُسجَّل |

### الأسبوع الثاني: المبيعات والحسابات والتسليم

| اليوم | ماذا سيظهر لكم | كيف نعرف أنه اكتمل؟ |
|------|------------------|----------------------|
| **٨** | إكمال أمر الإنتاج: استهلاك مواد + هدر + منتج نهائي | إغلاق الأمر يظهر الناتج والفرق عن المتوقع |
| **٩** | فواتير المبيعات والسحوبات وخصم المخزون تلقائياً | بيع منتج نهائي ينقص رصيد مستودع المنتجات |
| **١٠** | قيود محاسبية أساسية + ضريبة قابلة للضبط لعُمان | كل عملية مهمة تولّد قيداً يمكن مراجعته |
| **١١** | تقارير الأرصدة والحركات + تتبع السلسلة من المورد حتى البيع | يمكن فتح منتج ورؤية رحلته كاملة |
| **١٢** | ضبط الصلاحيات بدقة + سجل العمليات + إعدادات الشركة (عملة عُماني…) | موظف المستودع لا يدخل شاشات المحاسبة |
| **١٣** | تجربة شاملة لمسار العمل من أول خطوة لآخرها وإصلاح الملاحظات | تشغيل المسار الكامل دون توقف |
| **١٤** | الإطلاق النهائي + نسخة احتياطية + دليل استخدام مختصر للإدارة | النظام يعمل على الرابط النهائي ومتاح للفريق |

## ما الذي يجب أن يعمل في نهاية الأسبوعين؟

تجربة تشغيل كاملة بهذا الترتيب:

1. إضافة مورد  
2. إضافة مواد خام  
3. إنشاء أمر شراء  
4. استلام البضاعة في مستودع المواد  
5. تعريف منتج نهائي  
6. إنشاء وصفة تصنيع  
7. فتح أمر إنتاج  
8. تحويل مواد للمستودع المناسب للتصنيع  
9. إكمال الإنتاج (استهلاك + هدر + ناتج)  
10. وصول المنتج النهائي لمستودع المنتجات  
11. إصدار فاتورة مبيعات وتأكيدها  
12. فتح شاشة التتبع ورؤية السلسلة من المورد حتى البيع  

إذا اكتملت هذه الخطوات بنجاح = النظام جاهز للاستخدام التجريبي الجاد.

## ما ليس ضمن الأسبوعين (يمكن لاحقاً)

- ربط أجهزة البصمة / الميزان / الباركود  
- نظام حضور وموارد بشرية متقدم  
- تطبيق جوال مستقل  
- فروع متعددة معقدة  

يُفضَّل تأجيلها بعد استقرار التشغيل اليومي.

## أسئلة مهمة لصاحب العمل  
**(يفضّل الإجابة عليها خلال أول ٣ أيام حتى لا يتأخر الإطلاق)**

### أولاً: شكل النظام النهائي

1. **هل سيستخدم النظام أكثر من شخص ومن أكثر من مكان** (مكتب + مصنع + إدارة)، أم من جهاز واحد داخل المصنع فقط؟  
2. **هل تفضّلون فتحه من المتصفح مثل أي موقع**، أم برنامجاً يُثبَّت على الكمبيوتر، أم الاثنين؟  
3. إذا أردتم أيقونة على سطح المكتب: **هل يكفي اختصار يفتح النظام مباشرة**، أم تحتاجون برنامجاً تقليدياً مثبتاً؟  
4. **هل يجب أن يعمل بدون إنترنت لفترات**، أم الاتصال المستمر مقبول؟  
5. **من سيستخدمه يومياً؟** (مدير، محاسب، أمين مستودع، مشغّل إنتاج، مبيعات) — وهل يستخدمون حواسيب أم جوالات أكثر؟  
6. **هل تحتاجون طباعة فواتير أو أوامر من طابعات داخل المصنع؟** وما نوعها تقريباً؟

### ثانياً: مكان تشغيل النظام (الاستضافة)

7. **أين تفضّلون حفظ بيانات المصنع وتشغيل النظام؟**  
   - على الإنترنت عبر خدمة سحابية جاهزة (أسهل وأسرع غالباً)  
   - على سيرفر مستأجر خاص بكم  
   - على جهاز/سيرفر داخل المصنع فقط  
8. **هل لديكم حالياً موقع/دومين واستضافة**، أم نفتح حسابات جديدة؟  
9. **هل تشترطون بقاء البيانات داخل سلطنة عُمان فقط** لأسباب خصوصية أو سياسة داخلية؟  
10. **النسخ الاحتياطي:** هل النسخ اليومي التلقائي مناسب؟ وكم مدة الاحتفاظ المطلوبة (أسبوع / شهر / ثلاثة أشهر)؟  
11. **هل تريدون نسخة تجريبية منفصلة** عن النسخة الحقيقية للتجربة قبل التغييرات؟  
12. **كم تقريباً عدد المستخدمين الذين يعملون معاً في نفس الوقت؟** (مثلاً ٥ أو ١٥ أو أكثر)

### ثالثاً: الخدمات والربط مع أنظمة أخرى

13. **هل تحتاجون إشعارات بريد إلكتروني** (تنبيه نقص مخزون / استلام) من الآن، أم لاحقاً؟  
14. **هل يوجد جهاز بصمة أو ميزان أو باركود يجب ربطه فوراً**، أم بعد الإطلاق؟  
15. **هل المحاسبة ستبقى داخل هذا النظام**، أم تحتاجون تصدير لملف Excel أو برنامج محاسبي آخر؟  
16. **هل لديكم متطلب فوترة إلكترونية أو ربط حكومي/ضريبي الآن في عُمان؟**

### رابعاً: التشغيل والتسليم

17. **من سيكون المسؤول عندكم عن إدارة المستخدمين والصلاحيات؟**  
18. **ما الأدوار الفعلية في المصنع؟** (مقترح: مدير / مستودع / إنتاج / محاسب / مبيعات / موارد بشرية)  
19. **هل تفضّلون تدريباً مباشراً** أم فيديو قصير + دليل استخدام عربي مكتوب؟  
20. **متى تعتبرون المشروع «منتهياً»؟**  
    - بعد تجربة المسار الكامل أعلاه؟  
    - بعد استخدام يومي حقيقي لأسبوع؟  
    - بعد جاهزية التقارير الشهرية؟

## توصية مبسّطة (للنقاش فقط)

| الخيار | مناسب متى؟ | ملاحظة |
|--------|------------|--------|
| **نظام ويب من المتصفح** | عدة مستخدمين وأماكن + تحديثات سريعة | الأنسب كأساس الآن |
| **أيقونة على سطح المكتب تفتح نفس النظام** | تريدون سهولة فتح سريعة بدون تعقيد | إضافة بسيطة لاحقاً |
| **برنامج ويندوز مثبت بالكامل** | سياسة داخلية تفرض برنامجاً تقليدياً | أعلى تكلفة صيانة |
| **تطبيق جوال مستقل** | عمل ميداني كثيف على الهاتف | خارج نطاق الأسبوعين |
| **تشغيل داخل المصنع فقط بدون سحابة** | إنترنت ضعيف أو سياسة بيانات صارمة | يحتاج جهاز وصيانة داخلية |

**التوصية الحالية للإدارة:** البدء بنظام ويب عربي يعمل من المتصفح، مع إمكانية إضافة اختصار سطح المكتب لاحقاً إذا رغبتم. شكل سطح المكتب الكامل أو الجوال يُقرَّر بعد إجابات الأسئلة أعلاه.

## ملاحظات للإدارة

- أي تأخير في إجابات أسئلة الاستضافة وشكل النظام قد يؤخر يوم الإطلاق (اليوم ١٤).  
- الأولوية خلال الأسبوعين: **دقة المخزون والمال** قبل التحسينات الشكلية.  
- بعد الإطلاق يمكن ترتيب مرحلة ثانية للأجهزة والجوال والموارد البشرية.
