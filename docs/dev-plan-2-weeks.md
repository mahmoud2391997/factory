# تقرير خطة التطوير — نظام ERP مصنع أعلاف (عُمان)

**المدة القصوى:** أسبوعان عمل (١٤ يوماً تقويمياً / ١٠–١٢ يوم عمل فعلي)  
**الهدف:** نظام تشغيلي جاهز للاستخدام التجريبي الكامل (Demo Workflow) ثم الإطلاق للإنتاج.  
**التقنية الحالية:** Next.js Full-Stack + PostgreSQL/Prisma + واجهة عربية RTL  
**تاريخ التقرير:** سبتمبر ٢٠٢٦  

> مبدأ حاكم: **سلامة الحركات والمخزون > جمال الواجهة**  
> مبدأ حاكم: **لا تعديل مخزون بدون دفتر حركات + Audit**

---

## 1) ملخص الحالة الحالية (ما تم إنجازه)

| البند | الحالة |
|--------|--------|
| Monorepo (web + database + shared) | ✅ منجز |
| مخطط Prisma الأساسي + migrations | ✅ منجز |
| تسجيل الدخول / JWT / الجلسة | ✅ منجز |
| RBAC أدوار وصلاحيات (أساسي) | ✅ منجز |
| Demo mode عند غياب قاعدة البيانات | ✅ منجز |
| نشر Vercel + إعدادات DATABASE_URL | ✅ منجز |
| هيكل ERP: تبويبات رئيسية/فرعية + نماذج Schema | ✅ منجز (واجهة + تخزين محلي تجريبي) |
| دفتر المخزون الحقيقي (Ledger APIs) | ⏳ متبقي |

## 3) مسار القبول النهائي (Demo Workflow — يجب أن يعمل في نهاية اليوم ١٣)

1. إنشاء مورد  
2. إنشاء مواد خام  
3. إنشاء أمر شراء (PO)  
4. استلام بضاعة (GR) → مستودع خام + دفتر + أثر محاسبي  
5. إنشاء منتج نهائي  
6. إنشاء وصفة / BOM  
7. إنشاء أمر إنتاج (حساب المتوقع)  
8. تحويل مواد: مستودع ١ → مستودع ٢  
9. إكمال الإنتاج (استهلاك + هدر + انحراف + مخرجات)  
10. إضافة المنتج النهائي لمستودع ٣  
11. فاتورة مبيعات وتأكيدها (مخزون + ذمم + إيراد + ضريبة + COGS)  
12. فتح صفحة التتبع ورؤية السلسلة كاملة

## 4) ما هو خارج نطاق الأسبوعين (لاحقاً إن لزم)

- تكامل أجهزة البصمة / الميزان / أجهزة المصنع (Adapters)  
- حضور وموارد بشرية متقدم  
- تطبيق جوال أصلي منفصل  
- تعدد شركات / فروع معقد  
- تكلفة متقدمة (FIFO طبقات كاملة) — الحد الأدنى: متوسط مرجح  

يمكن جدولتها في **الأسبوع ٣–٤** بعد الإطلاق التشغيلي.

## 6) أسئلة عربية لصاحب القرار (استضافة / خدمات / شكل المنتج النهائي)

> يُفضَّل الإجابة كتابياً قبل **اليوم ٣** حتى لا يتأخر الإطلاق.

### أ) شكل المنتج النهائي (Web / Desktop / غيره)

1. **هل النظام سيُستخدم من عدة أجهزة ومواقع (مكتب + مصنع + إدارة) عبر الإنترنت، أم من جهاز واحد داخل المصنع فقط؟**  
2. **هل المطلوب تطبيق ويب يفتح من المتصفح (Chrome/Edge)، أم برنامج سطح مكتب يُثبَّت على ويندوز، أم الاثنان معاً؟**  
3. إذا كان سطح مكتب مطلوباً: **هل يكفي “اختصار لمتصفح يعرض النظام” (PWA / Electron غلاف خفيف)، أم تحتاجون تطبيقاً أصلياً منفصلاً بالكامل؟**  
4. **هل يجب أن يعمل النظام بدون إنترنت لفترات (Offline)، أم الاتصال الدائم مقبول؟**  
5. **من سيستخدم النظام يومياً؟** (مدير، محاسب، أمين مستودع، مشغّل خط إنتاج، مبيعات) — وهل يستخدمون جوالات أم حواسيب؟  
6. **هل تحتاجون طباعة فواتير/أوامر من طابعات حرارية أو شبكة داخل المصنع؟** وما نوع الطابعات؟

### ب) الاستضافة والخوادم

7. **أين تفضّلون تشغيل النظام؟**  
   - سحابة جاهزة (مثل Vercel + قاعدة Neon/Vercel Postgres)  
   - سيرفر خاص لديكم (VPS داخل عُمان أو خارجها)  
   - سيرفر داخل المصنع (On-premise)  
8. **هل لديكم حالياً دومين وشركة استضافة، أم ننشئ حسابات جديدة؟**  
9. **ما متطلبات الأمان والخصوصية؟** هل البيانات يجب أن تبقى داخل سلطنة عُمان فقط؟  
10. **من يدير النسخ الاحتياطي؟** يومي تلقائي مقبول؟ وكم مدة الاحتفاظ (٧ / ٣٠ / ٩٠ يوماً)؟  
11. **هل تحتاجون بيئة تجريبية (Staging) منفصلة عن الإنتاج؟**  
12. **ما ساعات العمل المتوقعة وعدد المستخدمين المتزامنين تقريباً؟** (مثلاً ٥ / ١٥ / ٥٠ مستخدم)

### ج) الخدمات الخارجية والتكاملات

13. **هل تحتاجون بريد إلكتروني للإشعارات (استلام/تنبيه مخزون) من الآن، أم لاحقاً؟**  
14. **هل يوجد جهاز بصمة / ميزان / باركود يجب ربطه في المرحلة الأولى، أم بعد الإطلاق؟**  
15. **هل المحاسبة ستبقى داخل النظام فقط، أم تحتاجون تصدير لبرنامج محاسبي آخر (Excel/نظام محلي)؟**  
16. **هل الفوترة الإلكترونية أو الربط مع جهات حكومية/ضريبية مطلوب الآن في عُمان؟**

### د) التشغيل والصلاحيات والتسليم

17. **من هو “مدير النظام” عندكم الذي يملك صلاحية إنشاء المستخدمين؟**  
18. **ما الأدوار الفعلية عندكم؟** (مطابقة مقترحة: مدير / مستودع / إنتاج / محاسب / مبيعات / موارد بشرية)  
19. **هل تريدون تدريب حضوري أم فيديو قصير + دليل عربي مكتوب؟**  
20. **ما تعريف “انتهى المشروع” بالنسبة لكم؟**  
    - تشغيل Demo كامل؟  
    - استخدام يومي حقيقي لأسبوع؟  
    - تقارير شهرية جاهزة؟  

### هـ) توصية تقنية مختصرة (للنقاش)

| الخيار | مناسب عندما | ملاحظة |
|--------|-------------|--------|
| **تطبيق ويب (موصى به كأساس)** | عدة مستخدمين، أكثر من موقع، تحديثات سريعة | ما نبنيه الآن |
| **PWA / اختصار سطح مكتب** | تريدون أيقونة على سطح المكتب بدون متصفح ظاهر | سريع ومنخفض التكلفة فوق الويب |
| **Electron / غلاف سطح مكتب** | سياسة داخلية تفرض “برنامج مثبّت” | أغلى صيانة؛ نفس المنطق تقريباً |
| **تطبيق جوال أصلي** | العمل الميداني الكثيف على الهاتف | خارج نطاق الأسبوعين |
| **On-premise فقط** | الإنترنت ضعيف أو سياسة بيانات صارمة | يحتاج سيرفر وصيانة داخلية |

**التوصية الافتراضية للمشروع الحالي:**  
**ويب أولاً (Next.js) + إمكانية PWA لاحقاً**، مع استضافة سحابية أو VPS حسب إجابات الأمان والموقع، وسطح المكتب فقط إذا كان متطلباً إدارياً صريحاً.
