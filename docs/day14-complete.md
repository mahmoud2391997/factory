# Day 14 — Complete ✅ (إغلاق خطة الأسبوعين)

**Status:** Done  
**Scope:** تشغيل المسار التشغيلي الكامل + تسليم ونسخ احتياطي + دليل استخدام

## ما الذي يعتبر “اكتمل”؟

النظام يعتبر مكتمل ضمن خطة الأسبوعين عندما ينجح مسار القبول التالي بدون توقف:

1. إضافة مورد  
2. إضافة مواد خام  
3. إنشاء أمر شراء  
4. اعتماد أمر الشراء  
5. استلام البضاعة إلى `WH_RAW` مع رقم دفعة وتاريخ صلاحية  
6. تحويل مواد إلى `WH_MFG`  
7. إنشاء وصفة BOM  
8. فتح أمر إنتاج  
9. إكمال الإنتاج (صرف + هدر + ناتج) → دخول المنتج النهائي إلى `WH_FG`  
10. إنشاء فاتورة مبيعات ثم تأكيدها → خصم مخزون + قيود + ضريبة  
11. تسجيل تحصيل  
12. فتح شاشة التتبع لرؤية السلسلة من المورد حتى البيع

مستند القبول: `docs/acceptance.md`  
دليل الاستخدام: `docs/user-manual-ar.md`

## دليل التشغيل السريع (للإدارة)

- شغّل الاختبارات:

```bash
pnpm test:erp
```

- شغّل النظام محلياً:

```bash
pnpm dev
```

## النسخ الاحتياطية

- من داخل النظام: **إعدادات الشركة → تنزيل نسخة احتياطية** (`/api/erp/backup`)  
- في وضع Postgres: قاعدة البيانات هي المصدر، وتنزيل JSON يعطي نسخة إضافية.

## الطباعة والتصدير

- طباعة أمر شراء: من شاشة أوامر الشراء → **طباعة**
- طباعة فاتورة: من شاشة الفواتير → **طباعة**
- ملصقات باركود: من شاشة المنتجات → **طباعة ملصقات الباركود**
- تصدير Excel: من شاشات الحسابات/المخزون عبر **تصدير Excel**
